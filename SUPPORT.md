# Support

Before asking for help, check the [README](./README.md) for installation, deployment, API, and testing guidance.

## Questions and usage help

For questions about using the application, API, or model, search the existing [issues](https://github.com/Sabtain-Dev/STT-Whisper-Pashto/issues) first. If you do not find an answer, open an issue with:

- A clear description of what you are trying to do.
- The relevant environment details (operating system, Python version, and deployment method).
- The exact error message and steps to reproduce it, with secrets and personal data removed.

## Bug reports and feature requests

Use the corresponding issue template when opening a bug report or suggesting a feature.

## Security concerns

Do not report vulnerabilities in a public issue. Follow the private reporting instructions in [the security policy](./.github/SECURITY.md).
